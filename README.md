## Implemented Algorithms

### 1. Fibonacci Sequence

The Fibonacci sequence is defined by:

F(0) = 0
F(1) = 1
F(n) = F(n-1) + F(n-2)

The implementation generates the first n terms
using an iterative approach.

**File:** `fibonacci.py`

**Time Complexity:** O(n)

### 2. Tower of Hanoi

Tower of Hanoi is a mathematical puzzle involving
three rods and n disks of different sizes.

The objective is to transfer all disks from the
source rod to the target rod while following
the puzzle rules.

The minimum number of moves is:

M(n) = 2^n - 1

The recursive algorithm follows:

T(n) = 2T(n-1) + 1

**File:** `tower_of_hanoi.py`

**Time Complexity:** O(2^n)
